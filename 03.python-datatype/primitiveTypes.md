# Primitive Types

## 1. int (Integer) Whole numbers (positive, negative, or zero).

**✔ Example**

```py
x = 10
y = -5
z = 0
```

**✔ Use Cases**

> Counters, loops , Mathematical operations, Indexing items, Age, quantity, IDs etc


## 2. float (Floating Point Number) Numbers with decimal points.

**✔ Example**

```py
price = 99.50
pi = 3.14159
```

**✔ Use Cases**

> Measurements

> Scientific calculations

> Financial calculations


### 🔹 3. complex Numbers containing a real and imaginary part.

**✔ Example**
```
c = 2 + 3j
```

**✔ Use Cases**

> Engineering

> Signal processing

> Scientific simulation

🔹 4. bool (Boolean)
✔ What is it?

Represents True / False values.

✔ Example
is_active = True
is_logged_in = False

✔ Use Cases

Conditions (if, while)

Flags (login status, feature ON/OFF)

Filtering data

🔹 5. str (String)
✔ What is it?

A sequence of characters.

✔ Example
name = "Punit"
msg = "Hello Python"

✔ Use Cases

Display messages

File paths

User input

Storing text from database/API
