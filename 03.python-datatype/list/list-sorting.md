# list sorting 

## sort()

```py

nums=[1,3,7,2,6,4,5]

// Ascending

nums.sort()

print(nums)

// Descending 

# nums.sort(reverse=True)

nums.reverse()

print(nums)
```



| `sort()`              | `sorted()`          |
| --------------------- | ------------------- |
| List method           | Built-in function   |
| Changes original list | Creates new list    |
| Returns `None`        | Returns sorted list |
