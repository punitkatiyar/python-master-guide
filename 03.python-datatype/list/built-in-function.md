## len() : Returns the number of items.

```py
students = ["Amit", "Rahul", "ravi", "Rohit"]

print(len(students))
```


## min(), max(), sum()

```py
marks = [75, 88, 92, 65, 80]

print(min(marks)) // 65
print(max(marks)) // 92
print(sum(marks)) // 400
```

## Average:

```py
average = sum(marks) / len(marks)

print(average)
```
