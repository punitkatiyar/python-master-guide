## List methods 

| Method      | Purpose            |
| ----------- | ------------------ |
| `append()`  | Add one item       |
| `extend()`  | Add multiple items |
| `insert()`  | Add at position    |
| `remove()`  | Remove by value    |
| `pop()`     | Remove by index    |
| `clear()`   | Remove everything  |
| `index()`   | Find position      |
| `count()`   | Count occurrences  |
| `sort()`    | Sort list          |
| `reverse()` | Reverse list       |
| `copy()`    | Copy list          |


## append ()

```py
bag=[]

bag.append("item 1")

bag.append("item 2")

bag.append("item 3")

print(bag)
```

## extend()

```py
list1=[1,2,3,4,5]

list2=[6,7,8,9,10]

list1.extend(list2)

print(list1)
```

## insert()

```py
bag.insert(1,"Ducat")

print(bag)

bag[0]="India"

print(bag)
```
