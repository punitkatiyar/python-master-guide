## List methods 

| Method      | Purpose            |
| ----------- | ------------------ |
| `append()`  | Add one item       |
| `extend()`  | Add multiple items |
| `insert()`  | Add at position    |
| `remove()`  | Remove by value    |
| `pop()`     | Remove by index    |
| `clear()`   | Remove everything  |
| `index()`   | Find position      |
| `count()`   | Count occurrences  |
| `sort()`    | Sort list          |
| `reverse()` | Reverse list       |
| `copy()`    | Copy list          |
