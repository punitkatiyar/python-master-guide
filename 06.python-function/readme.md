# Python Function 

A function is a **reusable block of code** that performs a specific task. Functions help you avoid repeating code, make programs easier to understand, and improve maintainability.

## 1. Basic Function
```python
def hello():
    print("Welcome to Python!")
hello()
```

## 2. Function with Parameters

```py
def hello(name):
    print("Welcome to",name,!!)
hello("User")

```

## 3. Function with Return Value

```py
def add(a, b):
    return a + b

result = add(10, 20)

print(result)
```
