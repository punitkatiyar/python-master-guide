## What is OOP?

**Object-Oriented Programming (OOP) is a programming paradigm that organizes code into objects rather than functions.**

## An Object is a real-world entity that has:

- Properties (Attributes)
- Behaviors (Methods)

| Attribute | Method       |
| --------- | ------------ |
| Color     | Start()      |
| Brand     | Stop()       |
| Speed     | Accelerate() |
