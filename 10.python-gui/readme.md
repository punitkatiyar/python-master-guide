# Python GUI

Python GUI (Graphical User Interface) development allows you to create desktop applications with windows, buttons, menus, forms, charts, and more. This roadmap takes you from beginner to advanced with examples and real-world use cases.

```py
import tkinter as tk

window = tk.Tk()

label = tk.Label(
    window,
    text="Hello Python"
)

label.pack()

window.mainloop()
```
