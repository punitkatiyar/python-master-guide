# Regex patterns are made using characters and special symbols.


| Pattern | Meaning |
|---|---|
| `.` | Any character except newline |
| `^` | Start of string |
| `$` | End of string |
| `*` | 0 or more occurrences |
| `+` | 1 or more occurrences |
| `?` | 0 or 1 occurrence |
| `{n}` | Exactly n occurrences |
| `{n,m}` | Between n and m occurrences |
| `[]` | Character set |
| `[^]` | Not in character set |
| `()` | Capturing group |
| `|` | OR |
| `\d` | Digit |
| `\D` | Not a digit |
| `\w` | Word character |
| `\W` | Non-word character |
| `\s` | Whitespace |
| `\S` | Non-whitespace |
